# Complete work without deleting it

Use native subagent completion or Captain crew reporting. A finished turn does not prove a task is done.

Before the final report, check acceptance, the actual diff and head SHA, checks and evidence, child status, pending questions, and any open PR. Preserve uncommitted or unpushed work and say exactly where it lives. Copy required evidence to the supplied project Drive location before a temporary machine can disappear.

A merge-ready PR still needs the user's merge decision. Report that ownership explicitly. Do not archive or delete threads, remove machines or managed worktrees, change a Captain, or merge as a side effect of completion. Cleanup needs its own audit and the user's selection.

Process repeat reports by branch and head SHA. Record new evidence or gates once. A missing report is a reporting gap, not permission to start an automation.
