## Dependency closure

No installed `loadout` CLI was available in this worker environment. The requested fallback is [check-grokbot-links.py](check-grokbot-links.py), which needs Python 3.11 or newer and only uses the standard library.

It reads `loadout.toml`, the `grokbot` machine's tags, and `machines/grokbot.toml`, then copies the selected skill directories into a disposable workflows layout. Starting with every selected `SKILL.md`, it follows Markdown links and static inline instruction paths, recursively checking referenced Markdown files. It rejects missing targets and paths escaping the materialized workflows directory. Code examples, URLs, anchors, and dynamic placeholders are excluded. One existing `personal-taste` reference, `assets/credits.json`, is an output generated by its image-download command rather than a shipped dependency; the explicit exception is counted in the output.

## Behavioral walkthroughs

These are instruction walkthroughs, not runtime tests:

| Situation | Documented result |
| --- | --- |
| Launch response is lost | Keep capacity reserved, reconcile candidate T3 threads and their briefs, then decide whether a retry is safe. |
| Same report arrives twice, or collection crashes | Preserve the source marker, reconcile the saved copy and board, and do not launch duplicate work. |
| Bob reports merge-ready | Read current PR/head/check state, retain ownership, and wait for Dan's merge decision. |
| Dan asks for status | Read/copy reports and show gates; do not launch, refill, send work-starting follow-ups, or settle. |
| Fleet delivers Wayfinder evidence | Attach evidence without starting a map, answering Dan's decisions, or refilling planning workers. |
| Bot delivery route is unknown | Keep delivery pending; use user-triggered chase. Never invent a T3 coordinator ID or wakeup API. |
| Support is asked to triage | Use the supplied acknowledgment rules; status and draft requests grant no sending permission. |
| Dan approves a support write | Launch a fresh Bob for that exact call, check prerequisites, verify afterward, and seek approval for the customer reply. |
| Worker has finished its turn | Check ownership, pending work, artifacts, checkout safety, PRs, and settle actions before settlement. |
| Coordinator is a T3 thread | Keep the reachable report-file and `t3_thread_send` transport. |
